# 決定記録

なぜそう決めたかの記録。いま何が成り立つかは主題の文書（[目次](../README.md)）に書き、ここには書かない。

## 書く場合

- 複数の案から選ぶ決定
- 以前の決定を変える決定

誤記の修正や、既存の決定の範囲内での書き足しには不要。

## 規則

- 1 つの決定に 1 ファイル。名前は `NNNN-<kebab-case の要約>.md`、ID は `D-NNNN`。番号は既存の最大 + 1。
- merge 後は本文を書き換えない。決定を変えるときは新しい記録を作り、古い記録の Status だけを `Superseded by D-NNNN` に変える。
- 影響する文書（Consequences に挙げたもの）は、同じ PR で更新する。
- 主題の文書は、書いている内容の根拠になった記録へリンクする。
- 書式は [template.md](template.md) に従う。
